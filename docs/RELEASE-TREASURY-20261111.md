# Казна и выплаты, 11.11.2026

## Возможности

Админка -> Кошелёк и AML -> Казна и вывод комиссий.

Поддерживаются USDT TRC-20, SOL, BTC и ETH с отдельных адресов сбора. Ручной вывод сначала рассчитывается, затем подтверждается отдельной кнопкой. Автовывод настраивается отдельно для каждой валюты: внешний адрес, порог, лимит одной выплаты, лимит сетевых расходов, остаток на адресе и интервал. Все четыре режима при выпуске оставлены ручными.

Для USDT получатель получает указанную сумму, газ оплачивается TRX с адреса казны. Для остальных валют сетевые расходы включены в сумму списания. ETH поддерживает обычные адреса, не контракты. Bitcoin требует подтверждённых UTXO и безопасных значений выходов и сдачи.

Внутренний доход не равен доступным блокчейн-средствам. Доступность ограничивается подтверждёнными сборами собственных комиссий, остатком внутреннего учёта и балансом отдельного адреса. Клиентские остатки, AML-резервы и необъяснённые поступления не становятся доступной казной. Существующие ограничения доказательства происхождения комиссий при консолидации сохраняются.

## Защита

Сумма резервируется в SQL-транзакции до отправки. Подписанная транзакция сохраняется до broadcast; после неопределённого ответа повторяется только та же подпись. Одна активная выплата на валюту. Изменение настроек инвалидирует старые расчёты, конкурентное сохранение настроек защищено revision. При известной ошибке сети возвращается неистраченная часть, неоднозначные операции остаются заблокированными до сверки.

Сбор и выплаты используют общую блокировку, включая использование TRX для газа. Закрытые ключи не возвращаются через API. Новые маршруты доступны только администраторам. TREASURY_PAYOUT_PAUSED=true запрещает новые подписи и повторный broadcast, но не сверку уже отправленного.

## Проверка и выпуск

- 134 backend-теста прошли на сервере.
- Изолированная MySQL: четыре валюты, резервирование, идемпотентность, сохранение подписи до отправки, возврат при ошибке, откат при конфликте уникальности. Внешняя сеть заменена тестовым транспортом.
- Интерфейс проверен на 320, 390, 768 и 1440 px: расчёт, отмена и подтверждение, отсутствие горизонтального переполнения и ошибок страницы. Запросы подменены, реальных выплат нет.
- Миграция 042 проверена повторным запуском. При первом запуске обнаружен и исправлен конфликт кодировок старой и новой таблиц до публикации кода.
- Опубликован backend и build, перезапущены только goblin-backend и goblin-frontend. Marketplace и посторонние процессы не затрагивались.
- Bitcoin API переключён с ограниченного ответами 429 Blockstream на mempool.space; genesis основной сети и оценки комиссии проверены с сервера.
- TronGrid сообщил об исчерпании дневных 100000 запросов. Для стабильной работы USDT требуется повышение лимита текущего ключа. Ограничение не обходилось и не заменялось фиктивным балансом.

На момент выпуска внутренний баланс казны: 0 USDT. Реальные подписания и переводы не выполнялись, работа с ненулевыми средствами не подтверждена.
