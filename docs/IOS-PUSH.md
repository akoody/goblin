# Уведомления на iPhone

Сайт поддерживает Web Push для установленного на главный экран веб-приложения на iOS/iPadOS 16.4+. Отдельного приложения App Store эта поставка не создаёт.

Открыть cryptogoblin.ru в Safari, выбрать «Поделиться», затем «На экран Домой». Открыть новую иконку, войти в аккаунт и нажать «Включить уведомления на iPhone». Подтвердить системное разрешение. Без установки на главный экран сайт показывает инструкцию.

Для iOS используется стандартный Web Push с VAPID, не Firebase Android SDK. Серверный ключ находится вне сайта в `/root/.config/goblin-push/vapid.json`, режим 600. Публичная часть доступна авторизованному клиенту. Подписки Apple проходят строгую проверку HTTPS-адреса, домена, ключей и размера, хранятся зашифрованно в существующей таблице устройств. Выход отвязывает устройство, отменяет подписку и очищает отображённые уведомления.

Подключены существующие события пополнений, выводов, сделок, рефералов и рассылки админа. Тексты автоматических уведомлений нейтральные. Нажатие открывает локальную страницу входа, проверяет аккаунт получателя и допустимый внутренний маршрут. Сервер повторно проверяет доступ к данным. История уведомлений и кеширование финансовых страниц не добавлены. Service worker не перехватывает загрузку страниц.

Проверены 127 серверных тестов, шифрование Web Push и VAPID-подпись без реальной отправки. Физический iPhone не подключён, доставка Apple и разрешение iOS ещё требуют проверки на устройстве. Работа доставки зависит также от настроек уведомлений и Focus.

Резервная копия перед публикацией: `/root/backups/goblin-20261110.QZqYz9`. Web Push установлен в изолированном backend runtime; существующие версии зависимостей сохранены. Ключи не включены в frontend или APK.
