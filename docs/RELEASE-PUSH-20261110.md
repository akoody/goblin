# Android push и Swap, 10.11.2026

## Опубликовано

Swap теперь открывает создание мемкоина. Старые адреса `/swap/create`, `/swap/tron` и `/create-coin` ведут на `/swap`. Кнопка «Создать свой мемкоин» переводит фокус к форме. Серверные операции обмена и финансовые политики не удалялись и не переключались.

Уведомления о новых сообщениях P2P и сделок гаранта отправляются участникам, кроме автора сообщения. Сообщения администратора участникам тоже вызывают push. Автоматические уведомления всем администраторам, новости, депозиты и отдельный маркет в эту поставку не входят.

Используется Firebase Cloud Messaging с отдельным сервисным аккаунтом `goblin-push-sender` и ролью Firebase Cloud Messaging API Admin. Прочие роли аккаунту не выдавались. Закрытый ключ размещён в `/root/.config/goblin-push/server-credential.json`, каталог 700, файл 600. В APK и frontend закрытого ключа нет. Не копировать этот файл в репозиторий или публичные резервные копии.

Миграция 041 добавляет только `push_devices`. Текст уведомления, его история и очередь в БД не сохраняются. Токены устройств шифруются AES-256-GCM, привязка проверяется по аккаунту и версии сессий. Для выхода запрос регистрации и отвязка сериализованы; старая сессия не может удалить привязку новой. Недействительные токены FCM удаляются. Неактивные устройства исключаются через 30 дней.

FCM получает нейтральный текст, ID получателя и внутренний путь сделки. Перед открытием проверяется аккаунт, а доступ к самой сделке повторно проверяет backend. Расходы и сообщения чата на экран блокировки не передаются. Срок ожидания доставки у FCM - до 5 минут. Сервер отправляет best-effort, без постоянной очереди и автоматического повторения неоднозначных отправок.

## Проверено

- 122 backend-теста локально и на сервере.
- Сборка Vite и Android release, Capacitor Push Notifications 7.0.7.
- APK: пакет `ru.cryptogoblin.app`, versionCode 2, версия 1.1.0, Android 6.0+, разрешение POST_NOTIFICATIONS.
- Сертификат APK совпадает с ранее опубликованным APK 1.0.0, допускается установка поверх.
- В APK нет закрытого серверного ключа.
- Swap и старые ссылки на 320, 390, 768 и 1440 px, кнопка фокусирует форму, навигация не создаёт заявки и транзакции.
- Production API: неавторизованный доступ запрещён; тестовая регистрация шифрует токен и затем удаляется при отвязке. FCM dry-run проходит аутентификацию и возвращает INVALID_ARGUMENT для заведомо ненастоящего токена, без реальной отправки.
- Публичная HTML-сборка совпадает с локальной по SHA-256, APK доступен по HTTPS.

Реальная доставка, открытие из уведомления и поведение в фоне не проверены: подключённого Android-устройства или эмулятора нет. Не считать dry-run доказательством доставки на телефон.

## Установка

Скачать `/downloads/cryptogoblin-android-v1.1.0.apk`, установить поверх старой версии, войти и нажать «Включить» в предложении уведомлений. Затем отправить сообщение этому аккаунту со второго аккаунта в тестовой сделке. Проверить открытое, свёрнутое и закрытое приложение, отказ в разрешении и выход из аккаунта.

Резервная копия перед публикацией: `/root/backups/goblin-20261110.RbGik9`. Миграция аддитивная, финансовые политики и процессы маркетов не менялись. Не восстанавливать полный дамп базы поверх новых пользовательских операций. Для отключения отправки достаточно перезапустить `goblin-backend` с `PUSH_ENABLED=false` и сохранить PM2.
