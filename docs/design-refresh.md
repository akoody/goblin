# Обновление интерфейса

Ветка интерфейса: светлая нейтральная основа, существующий Montserrat в бирже,
Manrope в маркете, тёмно-зелёный акцент #28633b. Навык uncodixfy использован для
устранения декоративных градиентов, стеклянных поверхностей, избыточных теней,
крупных округлений и перегруженной типографики. SVG графики и изображения товаров
не заменены декоративными заглушками. Финансовые API и расчёты не меняются.

## Основные изменения

- Главная: разные состояния гостя и аккаунта; обзор сервисов вместо огромного
  приветственного баннера, реальные доступные балансы и число активных сделок.
  При недоступных данных показывается отсутствие данных, не выдуманный ноль.
- Шапка: пять основных направлений, остальные — в раскрывающемся меню на всех
  экранах. Отдельное меню аккаунта, Escape, aria-expanded, доступные focus-состояния.
- Формы авторизации: видимые подписи над полями вместо плавающих подписей,
  компактные формы; регистрация и восстановление используют те же компоненты.
- Торговля: спокойные панели, читаемые действия и стакан, адаптация планшета.
- P2P, профиль, поддержка, процессинг, NFT, гарант и админка: единые поверхности,
  размеры округлений и веса шрифта. Нижняя мобильная P2P-навигация не плавает
  отдельной карточкой. Админ-заголовок соответствует открытому разделу.
- Маркет: все страницы и формы используют общую зелёную палитру, компактные
  скругления и фон; библиотека и категории без больших декоративных обложек.
  Каталог, фильтры, сделки и серверные действия сохранены.

## Проверка

`npm run build`, `npm run build --prefix apps/market`, `npm test --prefix backend`.
`node scripts/check-design-ui.mjs`: гостевые/авторизованные состояния, шесть
ширин 320–1920, главная, торговля, P2P и сделка, профиль, кошелёк, формы, помощь,
процессинг, NFT и админка. Проверка выбора цены стакана и меню.
`node scripts/check-market-design.mjs`: 66 комбинаций маршрутов и ширин;
публичный каталог читается без изменений, пользовательские данные подставные.
Отдельные проверки поиска админки, переключателей и реферального интерфейса.

Автотесты интерфейса используют изолированные ответы API. Они не подтверждают
проведение платежа, отправку писем или работу AML. Не создают реальных сделок
и не меняют балансы. Перед production-выкладкой нужно отдельно согласовать
визуальный результат и проверить сборки в целевой среде.

Проверено локально: 162 комбинации маршрутов/состояний/ширин основной части,
66 комбинаций маркета, 21 гостевой сценарий собранной Vite production-сборки.
31 backend-тест пройден; обе frontend-сборки успешны. Дополнительно проверены
поиск админки, доступность разделов и реферальный экран с подставными API.
Предпросмотр главной: `docs/screenshots/design-home-desktop.png` и
`docs/screenshots/design-home-mobile.png`; маркета — `design-market-*.png`.
Выложено 16.10.2026 на cryptogoblin.ru по запросу пользователя. Маркет собран
на Linux в `/root/goblin-market-design-20261016`, проверен на временном порту
8083 и переведён в PM2 `goblin-market` на loopback 8081. Временный процесс
остановлен. Резервная копия исходников и Vite-сборки:
`/root/goblin-backups/pre-design-20261016.tar.gz`. Предыдущая standalone-версия
маркета `/root/goblin-market-availability.G5qJFM` сохранена. Старые Vite assets
оставлены для уже открытых вкладок; новая index.html опубликована после assets.
Backend, база и финансовые настройки при выкладке не изменялись.
После публикации пройдены 24 проверки публичных страниц на ширинах
320/390/768/1024/1440/1920 с настоящими API без создания операций.
Проверены HTTP-маршруты и реальные административные read-only API:
поиск, права доступа, доступность разделов, политика комиссии и история.
