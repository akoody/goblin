# Браузерные QA-проверки

Скрипты `check-*.mjs` открывают интерфейс в Chrome через `playwright-core` и проверяют разделы на разных ширинах экрана. API в большинстве из них подменяется заглушками, поэтому база и деньги не затрагиваются.

Запуск из корня проекта:

```bash
npx vite --host 127.0.0.1 --port 5178    # в отдельном терминале; порт скрипта указан в его начале
node scripts/check-design-ui.mjs
```

- Chrome берётся из `/Applications/Google Chrome.app`; другой путь: `CHROME_PATH=/path/to/chrome`.
- Адрес интерфейса задаётся переменной из начала скрипта (`DESIGN_UI_BASE`, `SWAP_UI_BASE` и т. д.), у скриптов разные порты по умолчанию.
- Каждый скрипт писался под конкретный выпуск (см. `docs/releases/`). После правок интерфейса часть проверок может устареть: падение на отсутствующей кнопке означает, что проверку пора обновить, а не что сломан выпуск.

`prepare-market.mjs` готовит маркет к выпуску; `*.remote.mjs` запускаются на продакшен-сервере.
