# Goblin Backend

Серверная часть Goblin отвечает за кошельки, P2P-сделки, торговый терминал, платёжный процессинг, NFT-подарки и события в реальном времени.

## Состав

- REST API на Express;
- авторизация и разграничение доступа на основе JWT;
- MySQL-схема с последовательными SQL-миграциями;
- Socket.IO-чаты для сделок и поддержки;
- сервисы кошелька, транзакций и генерации адресов;
- matching engine для SPOT и FUTURES;
- isolated margin, funding и контроль риска;
- рыночные данные Binance с резервным источником Bybit;
- административные сценарии и журналирование операций.

## Торговая модель

Поддерживаются пары BTC/USDT и ETH/USDT. Лимитные ордера исполняются с приоритетом цены и времени и допускают частичное исполнение. Рыночные ордера используют модель fill-or-kill. Для фьючерсов реализован one-way mode с плечом от 1x до 20x, резервированием маржи и периодической проверкой ликвидационных порогов.

Согласованность операций обеспечивается транзакциями MySQL, блокировками строк и advisory lock на комбинацию рынка и торговой пары.
